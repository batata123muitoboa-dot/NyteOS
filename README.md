A lightweight Operating System made from scratch using Assembly and C. (beta/experimental)

## Hardware Requirements

### Minimum
- CPU: Pentium 4 2.8 GHz
- RAM: 3 MB
- GPU: Intel GMA 950
- Storage: 300 KB

### Recommended
- CPU: Intel Core 2 Duo E8400 or better
- RAM: 16 MB
- GPU: Intel GMA X4500 or better
- Storage: 2 MB

### Architecture
- x86 (32-bit)
